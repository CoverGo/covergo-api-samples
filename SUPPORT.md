# Support

These samples are reference material, not a supported product. There is no SLA on this
repository.

## Where to go

| You want to | Go to |
| --- | --- |
| Report a bug in a sample, or ask for one | An [issue](../../issues) on this repository |
| Understand a CoverGo API — operations, error shapes, idempotency | The published API reference; ask your CoverGo contact for access |
| Get help with your own integration, tenant, or credentials | Your CoverGo representative |
| Report a vulnerability | [SECURITY.md](SECURITY.md) — never a public issue |

Questions about your tenant's configuration, provisioning, or reference data cannot be
answered here — they need someone with access to your environment.

## Before opening an issue

Say what you ran and what came back. A sample that fails against your tenant is often a
configuration difference rather than a bug in the code, and the error message is what
distinguishes the two. Never paste a token, a credential, or customer data into an issue.
